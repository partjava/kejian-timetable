# XML 布局拆分：第一阶段

## 目的与基准

把固定界面结构从 Java 移到 Android XML，便于课堂学习、预览与答辩。保留现有外观与功能，不重新设计 UI。

源码基准为 v1.2.1 提交 `ba9195f`。本阶段只做设置页、AI 配置页、添加/编辑课程弹窗；今日课程、全部课程、详情、导入预览与课表网格不在本阶段迁移。

## 方案选择

- 采用分阶段迁移：固定控件使用 XML，动态内容继续由 Java 填充与绑定，逐页验证。
- 不采用一次迁移全部页面：改动范围过大，不利于定位回归。
- 不采用仅把空容器移进 XML：输入框、按钮及固定布局应真实存在于 XML，而非继续全部由 Java 创建。

## 文件与职责

| 文件 | 内容 |
|---|---|
| `res/layout/page_settings.xml` | 设置分组、项目容器、开关、底部说明 |
| `res/layout/item_setting.xml` | 可复用设置项标题、说明、点击区域 |
| `res/layout/item_setting_toggle.xml` | 可复用设置开关布局 |
| `res/layout/page_ai_settings.xml` | API 地址、模型、密钥输入框，状态提示，获取模型、测试、保存和返回按钮 |
| `res/layout/dialog_course_editor.xml` | 弹窗标题、课程信息、星期节次、周次区域、备注、颜色区域、关闭和保存按钮 |
| `res/values/strings.xml`、`colors.xml`、`dimens.xml` 与现有 `styles.xml` | 迁移页面使用的静态文字、颜色、尺寸、共用样式 |
| `res/drawable/` 下必要的 shape/selector | 输入框、按钮、卡片静态背景与状态 |

文件名为实现约定；现有同名文件存在时合并，不覆盖无关资源。布局采用已有原生 Android 控件，不引入新 UI 框架或依赖。

Java 通过 inflate 与 findViewById 获取 XML 控件，负责数据显示、事件、校验与状态更新。MainActivity 保留设置入口和业务回调，ImportController 保留 AI 请求及取消/防旧结果逻辑，CourseEditor 保留校验和 Saved 回调。允许提取小型绑定方法，但不进行无关架构改造。

课程周次格子数量由学期决定、颜色格子由色板决定：XML 提供固定区域，Java 按数据填充；保留单双周、长按范围选择、自定义取色及选择状态绘制。课表网格的自定义 Java 绘制不改。

## 数据与行为约束

- 不改数据库结构、数据库名称、课程或学期数据、SharedPreferences 键名、密钥加密方式。
- 不改 AI 地址规范化、请求格式、测试结果失效规则、取消逻辑与导入确认流程。
- 不改包名或签名；不在用户手机或原有模拟器正式包中清数据、安装或卸载。
- 不自动推送 GitHub、不自动发布 Release；保留旧 APK，不覆盖旧版本文件。
- XML 输入类型、密码遮蔽、单行/多行、焦点与滚动行为须与原版对应；密钥字段继续禁止保存控件状态。
- 点击后仍调用原有逻辑；错误仍显示原有提示，失败不关闭编辑弹窗、不报告保存成功。

## 验证与交付

1. 迁移前记录三页基准截图和关键行为，使用隔离 QA 包与虚构数据。
2. 增加 XML 控件存在性及交互回归检查；验证设置入口、周末开关持久化、AI 保存/测试状态、课程新增编辑和非法输入校验。
3. 保留并运行 v1.2.1 回归测试、纯 Java 测试和隐私检查；不调用真实付费 AI。
4. 构建与 Lint 检查，报告实际错误/警告；对比三页的布局、滚动、键盘、按钮可达性。模拟器验证不能代表所有真机适配。
5. 输出变更说明，列清每个 XML 对应的 Java 方法，帮助用户学习。测试通过后再生成单独的新 APK；明确签名类型，不覆盖旧包。
