# 课间实施计划

目标：交付可打开、可编译的 Java 安卓课表工程、调试 APK、本地导入服务、操作说明和实际运行截图。

架构：原生 Java Activity + XML 页面容器，SQLite 保存上课安排，SharedPreferences 保存当前学期和显示选项。一个课程可有多个星期、周次、教室安排。导入服务单独运行，Python 读取旧版 XLS、新版 XLSX、CSV，配置外部 AI API 后可使用智能解析及图片识别。服务不保存上传文件，默认只监听本机。

## 已确认设计
- 白色背景、蓝紫色主色、淡彩课程块；底部课表、今日、课程、设置。
- 七天/五天切换，默认七天，周末数据不删除，配置持久保存。
- 学期起始日、总周数、每日1–16节可设置；默认12节，包含晚间。
- 新增、编辑、删除安排；周次支持不连续集合；详情、搜索、学期管理、作息、备份恢复。
- 智能导入具有文件选择、上传确认、明确模式、进度、结果预览、逐项编辑、批量保存、重复和冲突检查。
- 未知星期/节次不编造，进入待补充；AI失败不假称成功、不静默降级。

## 文件边界
- app/src/main/java/com/kejian/app/MainActivity.java：导航、课表、今日、课程、设置及页面集成。
- Course.java / ScheduleRules.java：数据字段、周次解析、重叠判断及合法性。
- ScheduleDb.java：SQLite、学期、备份与事务导入。
- Ui.java / TimetableView.java：一致视觉组件和课程网格。
- CourseEditor.java / ImportController.java：编辑表单和导入流程。
- app/src/main/res：XML 主布局、配色、主题和图标。
- server：文件解析、AI调用、HTTP入口、验证测试与启动脚本。
