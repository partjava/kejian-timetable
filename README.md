# 个人课表

本人自用的安卓课表应用。包名 `com.kejian.app`，当前版本 **1.2.5**（versionCode 10）。最新源码统一维护在 **main** 分支，包含 XML 布局拆分版本。

## 1.2.5 更新

- 更多页面改用 XML + Java：设置、AI 配置、课程编辑、取色器、学期编辑和列表卡片；课表网格仍由 Java 自定义绘制。
- 修复渐变透明度串用，分离画笔并缓存渐变对象，移除课程卡片左侧装饰竖条。
- 今天的课程使用原本保存的纯色，其他日期保持渐变；关闭“突出显示今天”后全部恢复渐变。
- 自动配色优先选择与已使用颜色视觉差异更大的候选。
- 新增“优化课程配色”：先勾选、预览，再确认保存；手选和旧版颜色默认保留。
- 修正字体配置，补充 XML 独立预览高度与示例文字。

手机安装请下载 [Releases](https://github.com/partjava/kejian-timetable/releases) 附件中的 APK；克隆源码后需自行构建。

## 1.2.1 修复

- 删除学期同时清除对应的内存草稿、磁盘草稿并取消识别；不存在的学期不能写入课程或待补充事项。
- 取消识别会终止排队任务，并在读文件后及发送请求前检查取消状态。已经发送给服务商的内容不能撤回，也不能保证免除已产生的费用。
- 修改 API 地址、模型或密钥后必须重新测试；旧请求的成功提示不再覆盖新配置。保存时区分“已通过测试”和“尚未验证”。
- CSV 超过2000行或100列明确报错，不再静默截断；保留引号内换行，末尾换行不算额外记录。

## 它是什么

管理自己的上课安排，日常查看和编辑可离线使用；AI 识别需要联网并向你配置的服务商发送表格文字。

- 按学期、周次、星期、节次管理课程，一周显示五天或七天。
- 在手机上导入：直接读教务导出的 `.xls`/`.csv`，再调用自己在“AI 配置”里填写的接口识别成课程。
- 课表存在应用私有 SQLite；API 密钥用系统 Keystore 加密保存。没有自建服务器，AI 识别等联网功能直接调用你配置的服务商。
- 全新安装是空白课表，只创建一个默认学期，不含任何预置课程。
- 旧版（“课间”）导出的备份仍可恢复，备份文件的格式标识是 `kejian-backup`。

| 识别结果 | 查看、修改、勾选课程，检查重复与冲突，确认后事务保存 |

## 课表规则

**周次与冲突**

- `1-3,5-17` 表示第 4 周不排课，不会被改写成连续 1–17 周；“单周”“双周”按钮生成具体周次集合。
- 同一门课可以有多项安排，各自保存周次、星期、节次、教师和教室。
- 重复导入同一安排会跳过；星期与节次相同且周次重叠时，需先修改或取消勾选，不会覆盖已有课程。
- 新建、导入或恢复第 13–16 节的安排会自动扩展可见节数。

**显示**

- “显示周末”默认开启，关闭后变成五天布局，周六周日的课程仍保留，再次开启即可看到。
- “突出显示今天”控制日期栏标记和课程卡片：今天使用保存的原始纯色，不额外加深；其他日期使用渐变。关闭后全部使用渐变，查看不含今天的教学周也不会误高亮。
- 深色纯色背景自动使用浅色文字；卡片保留图标与标签，不再绘制左侧装饰竖条。

**颜色**

- 同一学期内同名课程共用颜色，手动改色会应用到该课程的所有安排。
- 自动分配比较渐变左右端点和强调色，选择与已用色的最小距离最大的候选，尽量避免相近色；课程名用于初始选择和平局处理。
- 相同课程名和已用色集合得到相同结果；不同导入顺序或学期配色可能产生不同结果。30 色候选用尽后允许复用，颜色不同也不保证人眼一定容易区分。
- 导入时保留已有同名课程的颜色与手选标记；新标题由本地算法自动分配，不依赖 AI 返回的颜色。
- 已有课表不会自动重排。进入“设置 → 优化课程配色”，勾选课程、查看左右新旧颜色预览后确认；取消不写入，未勾选的不改变。
- 手选颜色及无法判断来源的旧版颜色默认不勾选；明确勾选并确认后，所选课程转为自动配色。批量操作前建议备份。
- 预览期间课表发生变化时拒绝应用过期方案，需重新打开预览。

**作息与预备铃**

- 预备铃按半天分段，不按节：上午、下午、晚上各一个，显示在该段第一节上方（第 1、5、9 节），点击可改。
- 每段的预备铃不能晚于该段第一节的上课时间，保存时检查。
- “今日”页只在“下一节”那张卡片上显示预备铃；已经开始的课再报预备铃没有意义。
- 作息钟点和预备铃的默认值取自一所学校的实际作息（经作者本人同意收录），不是占位数字，也不代表其他学校，在作息页面可以改成自己的。

**删除**

- 三个入口：课程卡片左滑露出红色“删除”、课程详情页底部的“删除这项安排”、学期管理里的“删除”。都会先弹确认框。
- 删除学期会连同该学期的课程和待补充事项一起删除，无法撤销，其他学期不受影响；最后一个学期不能删除。删之前建议先备份。

**待补充事项**

- 识别草稿会保留；AI 认出了课名但没认出时间的安排存在“设置 → 待补充事项”，补齐后进入正式课表。

## 导入课表

1. “设置 → AI 配置”填写接口地址和 API 密钥。不记得模型名就点“获取模型列表”：它从聊天地址推出 `/models`（例如 `https://api.deepseek.com/chat/completions` → `https://api.deepseek.com/models`），列出该密钥可用的模型供点选；服务商没有这个接口时会在状态行说明，手动填写同样可用。
2. 点“测试连接”。只发一条极小请求，一次验证地址可达、密钥有效、模型名正确、接口支持 JSON 输出。
3. 显示“连接成功”后点“保存配置”。
4. 打开“智能导入”，选 `.xls` 或 `.csv`，点“开始识别”并确认发送。
5. 表格在本机读取，单元格文字发送给该服务商，返回结果交给你核对；检查课程、周次、教室和目标学期后确认保存。

支持 `.xls`（教务导出的二进制 Excel）和 `.csv`，单文件最大 8 MB。`.xlsx` 请先另存为 `.xls` 或 `.csv`。本版不识别 PDF 和课表截图。可用 `server/fixtures/synthetic.csv` 试跑，它是虚构数据，不会预装到 App 里。

识别质量取决于所选服务商与模型，不能保证所有表格格式都准确，仍需人工核对。调用失败会原样报出 HTTP 状态码和原因，不会偷偷降级成别的解析方式。

## 密钥与隐私

API 密钥只在手机本机保存，**不写入源码、不写入安装包、也不随课表备份导出**。

- 密钥用 Android Keystore 里的 AES-256/GCM 密钥加密，密文存在应用私有 SharedPreferences（`aiKey`）。Keystore 密钥无法从设备导出，密文拷到别处也解不开。
- 密钥不随 Android 备份迁移；备份文件里只有课表，没有密钥。
- 换机恢复数据、或修改锁屏凭据后 Keystore 密钥会失效。此时 App 清掉旧密文并提示重新输入，不会崩溃。
- 接口地址与模型名以明文保存（不敏感）。
- 接口地址要求 HTTPS，仅 `127.0.0.1`、`localhost`、`10.0.2.2` 允许 HTTP。地址可带查询参数（Azure OpenAI 的 `?api-version=` 需要），不允许包含用户名密码或 `#` 片段。

备份包含所有学期、课程和待补充事项。恢复会新增带“恢复”标记的学期，不清空原有数据；作息钟点、显示偏好和 AI 配置（含密钥）都不随备份迁移。

## 构建与安装

环境：Android Studio 内置 JDK、AGP 9.3.2、Gradle 9.5.0、API 37 SDK；最低 Android 8.0（minSdk 26），targetSdk 35。业务代码全部是 Java，没有 Kotlin 源码，没有显式声明第三方应用依赖。界面采用 XML 布局 + Java 绑定；部分动态界面由 Java 创建，课表网格使用 Canvas 绘制。

在 Android Studio 打开仓库根目录，使用 `main` 分支。以下 JAVA_HOME 是本机示例，请换成你的 JDK 路径。`assembleDebug` 生成的是调试签名 APK，不是正式发行签名包。

```powershell
$env:JAVA_HOME="D:\android\android\jbr"
.\gradlew.bat :app:assembleDebug :app:lintDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

覆盖安装会保留原有数据，不会自动清空。若要让已安装的手机也回到空白状态，先备份需要保留的内容，再到系统“应用信息”里清除“个人课表”的存储数据（不是只清缓存）；此操作会删掉该手机上的全部课表与设置。

测试：

```powershell
tests\run-pure-java.cmd                  # 纯 Java：配色、周次解析、XLS 读取
python -m unittest discover -s tests     # 仓库卫生检查：密钥与隐私文件
```

## 项目结构

设置、AI 配置、课程编辑、取色器、学期编辑及课程/学期卡片现采用 XML 布局 + Java 逻辑。学习入口见 [XML 与 Java 对照说明](docs/xml-layout-migration.md)。并非所有页面都已拆分，课表网格继续自定义绘制。

| 文件 | 作用 |
|---|---|
| `app/src/main/java/com/kejian/app/MainActivity.java` | 四个主页面、详情、学期、作息与设置页面的组织 |
| `app/src/main/res/layout/activity_main.xml` | 页面容器与底部导航的 XML 布局 |
| `Ui.java` | 共用字号、间距、按钮、输入框、图标 |
| `TimetableView.java` | 课程网格、五天/七天绘制与点击 |
| `CourseEditor.java` | 添加和编辑课程表单、周次格子、色板 |
| `ColorPicker.java` | 自定义颜色的 RGB 取色对话框 |
| `ColorPlan.java` / `ColorOptimization.java` | 只读配色方案、勾选与新旧颜色预览、确认应用 |
| `SwipeRow.java` | 卡片左滑露出删除键 |
| `Course.java` / `CourseColors.java` / `ScheduleRules.java` | 课程字段、配色规则、周次解析与冲突判断 |
| `ScheduleDb.java` | SQLite 读写、批量导入、待补充事项、备份恢复 |
| `ImportController.java` | 文件选择、调用 AI、结果预览、草稿保存 |
| `AiConfig.java` / `AiClient.java` | 接口地址与模型存储、密钥的 Keystore 加解密、直连服务商 |
| `XlsReader.java` / `Sheets.java` | 本机读取 `.xls`（OLE2 + BIFF8）与 `.csv` |
| `ImportValidator.java` | 校验模型返回的字段与范围，不合格就拒绝 |
| `server/` | 旧版电脑端辅助服务，App 已不再调用，保留作独立工具与移植来源 |
