# 个人课表 · Java 安卓应用

当前版本：1.2.0。应用已从“课间”更名为“个人课表”，仍为空白课表版；包名不变，支持覆盖更新，兼容旧版备份。下方历史名称“课间”均指同一应用。

1.1.0 起导入不再依赖电脑：App 自己读取 XLS/CSV，并用你在「AI 配置」里填写的接口地址、模型和密钥直接调用 AI。密钥经系统 Keystore 加密只存在本机。

1.2.0 改进了课表的日常操作：卡片左滑即可删除、设置里可以删除整个学期、同一门课的颜色保证一致、配色扩到 30 色并可自定义、今天的课程块盖一层白色磨砂、待补充事项有红点提醒、上课周次改为点格子。

这是一个可以用 Android Studio 打开的 Java 安卓工程。**1.0.1 为空白课表版：全新安装只创建默认学期，不包含任何预置课程或真实课表样本。** 可手动添加课程或自行选择文件导入。默认学期日期仅为可修改的初始设置，请按学校实际开学日期调整。

覆盖安装会保留旧版已保存的数据，不会自动清空。如果希望已安装的手机也恢复为空白，请先备份需要保留的数据，再到系统应用信息中清除“课间”的存储数据（不是只清缓存）；此操作会删除该手机中的全部课表与设置。

## 先运行看看

1. 在 Android Studio 选择 **File → Open**，打开 `KeJian` 文件夹。选择包含 `settings.gradle` 的这一层，不是里面的 `app` 文件夹。
2. 等待 Gradle 同步完成。提示需要 SDK 时允许安装项目要求的 SDK；此电脑已验证使用 API 37 SDK、Gradle 9.5.0、Android Gradle Plugin 9.3.2 和 Android Studio 内置 JDK。
3. 顶部选择 `app` 和模拟器，点击绿色运行按钮。
4. 若只想体验，可安装交付的 `课间-debug.apk`，或直接使用本电脑模拟器中已安装的“课间”。最低支持 Android 8.0（API 26）；当前实测为 Android 17 / API 37 模拟器。

这个工程没有修改你原来的 `My Application` 项目。它有独立应用包名 `com.kejian.app`。

### 课表规则

- “显示周末”默认开启。关闭后变为五天布局，周六周日课程仍保留；再次开启即可查看。
- 同一门课可以有多项安排，分别保存上课周次、星期、节次、教师和教室。
- `1-3,5-17` 表示第4周不排课，不会被改成连续1–17周。单周、双周按钮生成具体周次集合。
- 重复导入同一安排会跳过。存在相同星期、节次且周次重叠的课程时，需先修改或取消勾选；不会覆盖旧课程。
- 新建/导入/恢复第13–16节的安排时会自动扩展可见节数。实际钟点请在作息页面核对设置。
- 预备铃按半天分段，不按节：上午、下午、晚上各一个，显示在该段第一节上方，也就是第1、5、9节。点击可改。每段的预备铃不能晚于该段第一节的上课时间，保存时会检查。「今日」页只在“下一节”那张卡片上显示它的预备铃 —— 已经开始的课再报预备铃没有意义。
- 识别草稿会保留；尚未确定时间的课程保存在“设置 → 待补充事项”。补充后会移入正式课表。
- 备份包含所有学期、课程和待补充事项。恢复会新增带“恢复”标记的学期，不清空原有数据；作息钟点、显示偏好和 AI 配置（含密钥）都不随备份迁移。
- 删除入口有三处：课程卡片左滑露出红色“删除”、课程详情页底部的“删除这项安排”、学期管理里的“删除”。都会先弹确认框。
- 同一学期内，课程名相同的所有安排共用一种颜色，不同的课程各用一种颜色。改色会一起应用；导入时同名课程一律采用已有颜色，AI 挑的颜色只作参考。
- 新增的课按课程名算出一个"本来就该用"的颜色；如果这个颜色已经被本学期另一门课占用，它会在**同一个色系**里换一档（色板每三个一组就是一个色系），所以一门课即使让了位，看起来还是它自己。同一学期超过 30 门课时才会重新出现两门课同色。因此同一门课在重装或换机后通常是同一个颜色，但不保证——让过位的课可能不同。
- 1.2.0 之前导入的课表可能几门课共用一个颜色。在「设置 → 重排课程颜色」点一下可以重排（会改写现有配色，建议先备份），改完的结果会写进数据库。
- 删除学期会连同该学期的课程和待补充事项一起删除，无法撤销，其他学期不受影响。删之前建议先“备份课表”。最后一个学期不能删除。

## 使用文件导入

1. 打开“设置 → AI 配置”，填写接口地址和 API 密钥。不记得模型名就点“获取模型列表”：它从聊天地址推出 `/models`（例如 `https://api.deepseek.com/chat/completions` → `https://api.deepseek.com/models`），把该密钥能用的模型列出来供你点选。服务商没提供这个接口时会在状态行说明，手动填写照样可用。
2. 点“测试连接”。它只发一条极小的请求，一次性验证地址可达、密钥有效、模型名正确、且接口支持 JSON 输出。
3. 显示“连接成功”后点“保存配置”。
4. 打开“智能导入”，选择 `.xls` 或 `.csv` 文件，点“开始识别”，确认发送。
5. App 在本机读取表格，把单元格文字发送给该服务商，再把返回结果交给你核对。检查课程、周次、教室和目标学期后确认保存。

支持 `.xls`（学校教务导出的二进制 Excel）和 `.csv`，单个文件最大 8 MB。`.xlsx` 请在 Excel 中另存为 `.xls` 或 `.csv`；本版不再识别课表截图，请在教务系统导出表格。

可用 `server/fixtures/synthetic.csv` 测试导入。这是虚构测试数据，不会预装到正式 App 中。把文件放到设备 Downloads，再通过系统文件选择器选择。

## 关于密钥

API 密钥只在手机本机保存，**不写入源码、不写入安装包、也不随课表备份导出**。

- 密钥用 Android Keystore 里的 AES-256/GCM 密钥加密，密文存在应用私有 SharedPreferences（`aiKey`）。Keystore 密钥无法从设备导出，因此把 `aiKey` 密文拷到别处也解不开。
- 密钥不随 Android 备份迁移，备份文件里也只有课表，没有密钥。
- 换机恢复数据、或修改锁屏凭据后，Keystore 密钥会失效。此时 App 会清掉旧密文并提示重新输入，不会崩溃。
- 接口地址与模型名以明文保存（不敏感）。

接口地址要求 HTTPS，只有 `127.0.0.1`、`localhost`、`10.0.2.2` 这几个本机地址允许 HTTP。地址里可以带查询参数（Azure OpenAI 的 `?api-version=` 需要），但不允许包含用户名密码或 `#` 片段。

**AI 验证范围：**识别质量取决于你选的服务商与模型，不能保证所有表格格式都准确，仍需人工确认。AI 调用失败时会原样报出 HTTP 状态码和错误原因，不会偷偷降级成别的解析方式。当前版本不支持 PDF 和课表截图。

## 文件在哪里、怎么学

| 文件 | 作用 |
|---|---|
| `app/src/main/res/layout/activity_main.xml` | 页面容器和底部导航的 XML 布局 |
| `app/src/main/java/com/kejian/app/MainActivity.java` | 四个主页面、详情、学期与作息页面的组织 |
| `Ui.java` | 共用字号、间距、按钮、输入框、图标 |
| `TimetableView.java` | 课程网格、五天/七天绘制与点击 |
| `CourseEditor.java` | 添加和编辑课程表单、周次格子、色板 |
| `ColorPicker.java` | 自定义颜色的 RGB 取色对话框 |
| `SwipeRow.java` | 卡片左滑露出删除键 |
| `Course.java` / `CourseColors.java` / `ScheduleRules.java` | 上课安排字段、配色与取色规则、周次解析、冲突判断 |
| `ScheduleDb.java` | SQLite、批量导入、待补充、备份恢复 |
| `ImportController.java` | 文件选择、调用 AI、结果预览、草稿保存 |
| `AiConfig.java` | 接口地址/模型存储，密钥的 Keystore 加解密与地址校验 |
| `AiClient.java` | 直连服务商的 Chat Completions 请求、「测试连接」与模型列表 |
| `XlsReader.java` / `Sheets.java` | 本机读取 .xls（OLE2 + BIFF8）与 .csv，生成提示词内容 |
| `ImportValidator.java` | 校验模型返回的字段与范围，不合格就拒绝 |
| `server/server.py` | 旧版电脑端辅助服务，保留作独立工具与参考实现，App 已不再依赖 |

安卓业务代码使用 Java；动态表单和课程网格由 Java 创建，整体容器使用 XML。导入链路全部在 App 内，不需要电脑配合。初学建议先看 `Course.java`，再看 `CourseEditor.java` 和 `ScheduleDb.java`，最后理解页面组织。

本版本已移除旧的真实课表资源、测试文件和页面截图。删除当前文件不会删除 Git 历史或 GitHub 已发布的旧安装包；公开发布前应另外处理旧版本及历史，检查自己后来添加的文件中是否包含隐私或密钥。
