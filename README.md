# 课间 · Java 安卓课表

这是一个可以用 Android Studio 打开的完整安卓工程。首次运行会预载你提供的“卓越实验班202401”课表：10门课程、16项上课安排、2项待补充事项。它们来自原始 XLS 的本地解析，不是 AI 在线识别结果。

## 先运行看看

1. 在 Android Studio 选择 **File → Open**，打开 `KeJian` 文件夹。选择包含 `settings.gradle` 的这一层，不是里面的 `app` 文件夹。
2. 等待 Gradle 同步完成。提示需要 SDK 时允许安装项目要求的 SDK；此电脑已验证使用 API 37 SDK、Gradle 9.5.0、Android Gradle Plugin 9.3.2 和 Android Studio 内置 JDK。
3. 顶部选择 `app` 和模拟器，点击绿色运行按钮。
4. 若只想体验，可安装交付的 `课间-debug.apk`，或直接使用本电脑模拟器中已安装的“课间”。最低支持 Android 8.0（API 26）；当前实测为 Android 17 / API 37 模拟器。

这个工程没有修改你原来的 `My Application` 项目。它有独立应用包名 `com.kejian.app`。

## 已实现的页面与功能

| 页面 | 功能 |
|---|---|
| 每周课表 | 切换教学周、显示日期、突出今天、点击课程详情、纵向滚动 |
| 今日课程 | 按时间查看当天安排，标记已结束、进行中、下一节 |
| 全部课程 | 按课程名、教师、教室搜索，查看同一课程的不同安排 |
| 课程详情 | 查看完整课程名、教师、教室、时间、周次，编辑或删除 |
| 添加/编辑课程 | 选择周一到周日、1–16节、自定义周次、单/双周、颜色与备注 |
| 学期管理 | 新建、编辑、切换学期；每学期课程独立保存 |
| 作息时间 | 设置每日1–16节，以及每节课起止时间；默认12节，含晚间 |
| 设置 | 周末显隐、今天高亮、服务配置、待补充事项、备份恢复 |
| 智能导入 | 选择 XLS/XLSX/CSV/图片，选择本地规则或 AI 模式，进度及失败提示 |
| 识别结果 | 查看、修改、勾选课程，检查重复与冲突，确认后事务保存 |

### 课表规则

- “显示周末”默认开启。关闭后变为五天布局，周六周日课程仍保留；再次开启即可查看。
- 同一门课可以有多项安排，分别保存上课周次、星期、节次、教师和教室。
- `1-3,5-17` 表示第4周不排课，不会被改成连续1–17周。单周、双周按钮生成具体周次集合。
- 重复导入同一安排会跳过。存在相同星期、节次且周次重叠的课程时，需先修改或取消勾选；不会覆盖旧课程。
- 新建/导入/恢复第13–16节的安排时会自动扩展可见节数。实际钟点请在作息页面核对设置。
- 识别草稿会保留；尚未确定时间的课程保存在“设置 → 待补充事项”。补充后会移入正式课表。
- 备份包含所有学期、课程和待补充事项。恢复会新增带“恢复”标记的学期，不清空原有数据；作息钟点、显示偏好和服务地址不随备份迁移。

## 使用文件导入

1. 双击 `server/start-server.cmd`。看到 `KeJian listening ...` 才代表启动成功，使用期间保持该窗口打开。
2. 本电脑可直接使用已有 Python 运行时；其他电脑需要 Python 3.10+。项目附带 xlrd 2.0.2，因此 XLS 解析不必现场联网安装依赖。
3. App 打开“设置 → 识别服务设置”，模拟器地址填 `http://10.0.2.2:8765`，点击“保存并检查连接”。
4. 打开“智能导入”，选择文件，再选“本地表格解析”。它无需 AI 密钥，但仍需电脑上的导入服务运行。
5. 点击“开始识别”，确认发送文件。检查返回的课程、周次、教室和目标学期后确认保存。

可用 `server/fixtures/sample.xls` 复现原课表。把文件拖入模拟器通常会放到 Downloads，再在系统文件选择器的 Downloads 中选择它。重复导入预载课表时，提示跳过16项是正常的。

USB 真机：先开启 USB 调试、连接电脑并授权，在电脑运行 `adb reverse tcp:8765 tcp:8765`，App 地址使用 `http://127.0.0.1:8765`。远程地址要求 HTTPS；开发服务没有完整公网鉴权和限流，不应直接公开部署。

## 接入真正的 AI

你需要提供服务商的三个配置：完整 HTTPS API 地址、模型名称、API 密钥。必须是支持 Chat Completions 请求格式的接口；识别图片还需要模型支持视觉输入。

停止已经运行的本地服务，打开 PowerShell，进入 `server` 文件夹，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-ai.ps1
```

依次输入接口地址、模型名称和密钥。密钥输入不会显示，保留在服务进程环境中，不写入 APK 或配置文件。也可以按 `server/README.md` 设置环境变量后启动。

回到 App 检查连接，显示“AI 已配置”后即可选择“AI 智能识别”。这个状态仅表示配置项存在；真正是否可用还取决于账号额度、网络、模型和服务商接口。AI 调用失败会明确报错，不会偷偷切换成本地解析。

**当前验证范围：**本地 XLS/XLSX/CSV 解析、App HTTP 联调与数据库保存已实测。AI 的请求构造、图片请求格式和结果校验通过模拟响应测试；没有配置真实 API 密钥，因此未声称通过真实模型在线识别测试。当前版本不支持 PDF。

## 文件在哪里、怎么学

| 文件 | 作用 |
|---|---|
| `app/src/main/res/layout/activity_main.xml` | 页面容器和底部导航的 XML 布局 |
| `app/src/main/java/com/kejian/app/MainActivity.java` | 四个主页面、详情、学期与作息页面的组织 |
| `Ui.java` | 共用字号、间距、按钮、输入框、图标 |
| `TimetableView.java` | 课程网格、五天/七天绘制与点击 |
| `CourseEditor.java` | 添加和编辑课程表单 |
| `Course.java` / `ScheduleRules.java` | 上课安排字段、周次解析、冲突判断 |
| `ScheduleDb.java` | SQLite、批量导入、待补充、备份恢复 |
| `ImportController.java` | 文件选择、异步请求、结果预览、草稿保存 |
| `server/server.py` | 文件解析、AI 请求、返回数据校验与 HTTP 服务 |

安卓业务代码使用 Java；动态表单和课程网格由 Java 创建，整体容器使用 XML。后端是单独的 Python 辅助服务，不是安卓代码。初学建议先看 `Course.java`，再看 `CourseEditor.java` 和 `ScheduleDb.java`，最后理解页面组织。

课表中的班级、教师、教室来自你提供的文件。公开分享源码前，可替换 `assets/sample-result.json` 和两个 `sample.xls` 测试样本。
